# Microcontroller Maze Game

C言語で制作したマイコン向け迷路ゲームです。棒倒し法で生成した迷路をTFTへ表示し、ジョイスティックで操作して制限時間内にゴールを目指します。
授業で配布されたひな形をもとに、迷路生成やゲームの進行処理などを実装しました。

## 主な実装

- 棒倒し法による15×20マスの迷路生成
- SDカードから読み込んだ画像のTFT表示
- ジョイスティックのA/D入力によるキャラクター操作
- タイマー割り込みによる制限時間とゲーム状態の管理
- スイッチ割り込みによる開始、一時停止、迷路の再生成
- 7セグメントLEDによる残り時間の表示
- ブザーによるゲームクリア・ゲームオーバー通知
- LCDによるクリア回数・ゲームオーバー回数の表示

## 使用技術

- C
- 組み込みプログラミング
- 割り込み処理
- A/D変換
- TFT、LCD、7セグメントLED、ブザー制御
